配車管理 事務所マニュアル

対象：配車を組む事務所スタッフ URL：/haisha 版：2026年10月15日版（最新仕様）

配車管理は、DS（電脳交通）から書き出したCSVを取り込んで担当者を割り当て、日々の配車を確認するための社内ツールです。このマニュアルは事務所で操作する方向けです。乗務員の方は別紙の「乗務員向けマニュアル」をご覧ください。

01開き方・ログイン

事務所の端末では、普段はログイン操作は不要です。URL（/haisha）を開けばそのまま予約が見られます。

✓ ふだんの利用

パスワードを聞かれる場合は、画面上部に出る案内に従って「ログインする」を押してください。それでも入れない場合は電波状況をご確認のうえ、管理者に連絡してください。

予約内容の編集・削除など一部の操作だけ、管理者のロック解除が必要です（後述）。

✓ 新しい版は自動で反映

画面を開きっぱなしにしていても、プログラムが更新されると数分以内に自動で再読み込みされます（入力中は終わるまで待ちます）。「変更したはずの表示が出ない」ときは、一度ページを再読み込み（Ctrl+F5）してください。

日別ボード・全体配車ボードは、開いたままにしていても30秒ごとに自動で最新化されます。他の人がCSVを取り込んだり担当者を割り当てたりした内容もすぐに反映されます（担当者・状態・チェックを選んでいる最中の20秒間は、選択が消えないよう更新を待ちます）。

ページの一番下の「文字サイズ」で、小・標準・大・特大を切り替えられます。「小」は1日分をできるだけスクロールせずに見たいとき、「大」「特大」は大きな画面を離れて見るときに使います。選んだ大きさは端末ごとに覚えられます。

03毎日の予約チェックと「全て確認済み」

予約の確認は、日勤（夕方・引き継ぐ前）→ 遅番（業務終了後）の順に、それぞれ紙の予約表と配車ボードをWチェックして、全予約の「済」にチェックを入れ、確認した人の名前を選んでサインします。チェックの漏れを防ぐため、終わるまで画面の一番上に警告が出続けます。日勤のサインは必須で、日勤が完了していないと、遅番（夜勤）も完了になりません。夕方18時から、画面の一番上の確認は「明日」の予約の分に切り替わるので、0時を待たずに確認できます（0時を過ぎると「本日」の表示に変わり、記録はそのまま引き継がれます）。

  1. 日勤：夕方・引き継ぐ前に、Wチェックして「日勤（夕方）の確認済み」

    紙の予約表と配車ボードをWチェックし、日別の配車ボードで全予約の「済」にチェックを入れます（キャンセルは対象外）。全部入ったら、画面の一番上の「日勤（夕方）の確認済み」にチェックを入れ、確認した日勤の人の名前を選びます。（「全て確認済み」を押したときの選択肢「日勤（夕方・引き継ぐ前）」からも同じように記録できます）「引き継ぎ」を記録したあと、また夕方18時に確認の対象が「明日」に切り替わったときに、このサインの画面が自動で出ます（明日の予約が全部チェック済みで、日勤のサインがまだのとき。「済」が残っていれば、先に済を入れるよう案内が出ます。18時の自動表示は、1つの端末で同じ日に1回だけです）。全部の「済」が入るまでは押せません（グレーのまま）。

  2. 遅番：業務終了後に、二人でWチェックして「全て確認済み」

    CSVを0時以降に出力し、最新（ダウンロード時間）を確認したうえで、二人でWチェックします。完了した分は、紙の予約表と配車ボードの両方にレ点を入れます（未完了の予約は、配車ボードにはレ点せず、紙のみ）。全ての「済」が入ったら、画面の一番上の「全て確認済み」にチェックを入れ、場面は「Wチェックが完了した」のまま、電話番ではない側の人の名前を選びます。日勤のサインが無いと押せません。

  3. やむを得ない場合：紙のみチェック → 翌朝の日勤が完了する

    遅番が二人でWチェックできないとき（相方が急病・事故・緊急の呼び出しなどで立ち会えない／乗務の終了時間が大きく違う／遅番が1名しかいない／DS・配車ボードの障害）は、紙の予約表のみにチェックします（配車ボードにはレ点しません）。翌朝、日勤が全て完了して「全て確認済み」にチェックし、場面「日勤が朝にチェックした」で日勤の人の名前を選びます（朝7時以降の本日分は、最初からこの場面が選ばれています）。

  4. サインする人と、選ぶ項目

    段階サインする人画面で選ぶ項目
    日勤（夕方・引き継ぐ前）確認した日勤の人「日勤（夕方）の確認済み」、または「全て確認済み」→「日勤（夕方・引き継ぐ前）」
    遅番（業務終了後、二人でWチェック完了後）電話番ではない側の人「全て確認済み」→「Wチェックが完了した」
    やむを得ない場合（紙のみチェック）→翌朝の日勤日勤の人「全て確認済み」→「日勤が朝にチェックした」

    サインできるのは、小林隼人・渡部晃・堀内洋伯・荒智章・目黒圭吾・中橋常郎・菅原元輝・小林結の8名だけです（日勤の候補は、確認する日の前日に日勤で出ている人。小林結さんはシフトに無いため、平日（土・日・祝日を除く）だけ日勤の候補に出ます）。サインした人は、責任をもって対応してください。選ばずには確定できません。

  5. 緑の表示に変わったら完了

    「✓ 本日の予約は全て確認済み　日勤（夕方）：○○（18:20）　確認：△△（01:17）」と出ます。誰がいつ確認したかが記録されます。押し間違えたときは、チェックを外すと取り消せます（確認のメッセージが出ます）。この緑の表示は、朝8時になると自動で消えます（記録は残ります）。

⚠ 日勤のサインは必須

日勤（夕方）の確認済みが入っていないと、遅番の「全て確認済み」は押せず、画面も緑（完了）になりません。「日勤（夕方）の確認済みが入っていません。日勤が完了しないと、遅番も完了になりません」と注意が出ます。

警告の出方

画面の表示意味すること
⚠ 予約確認が終わっていません朝7時前。未チェックの予約が残っている「済」を入れていく
🚨 朝7時を過ぎても…7時を過ぎても未完了。太い赤枠で大きく出るすぐ再チェックして、最後に「全て確認済み」を入れる
「全て確認済み」のあとに未チェックが…確認のあとに新しい予約が入った等で、未チェックが出た。記録は無効になるその予約を確認して「済」を入れ、もう一度「全て確認済み」を押す
日勤（夕方）の確認済みが入っていません全予約チェック済みだが、日勤のサインが無い。遅番も完了にならない日勤の人が「日勤（夕方）の確認済み」にチェックして名前を選ぶ
✓ 全て確認済み全予約チェック済みで、日勤・遅番の確認者の記録もある何もしなくてよい（朝8時になると表示は消える）

✓ 見落とし防止

警告は日別・全体・予約一覧のどのタブでも一番上に出ます。ブラウザのタブ名にも「⚠未確認」が付くので、別のタブを見ていても気付けます。「未チェックを確認する」ボタンを押すと、今日の日別ボードが開き、時間がたって自動で隠れた予約も表示されます。メールやスマホへのプッシュ通知はしていません。

ご注意

日付が変わる（0時）と、対象が新しい日に切り替わり、その日の予約が未チェックの状態から始まります。日中にDSから新しい予約が入ると、その予約は未チェックなので、再び赤になります。

04画面上部の警告・最終取込

不具合や取り込みの滞りに気付けるよう、画面の上に警告が出ます。画面は塞がず、直ると自動で消えます。

警告意味・対応
最新の予約を読み込めていません（最後に更新できたのは 10:36）通信が途切れた、ログインが切れた、システム側（Supabase）の障害など。理由も一緒に出る。通信が戻れば自動で消える
画面の自動更新が止まっている可能性があります3分以上更新されていないとき。ページを再読み込みする
CSVの取り込みから○時間以上たっています日中（7〜23時）に、最後の取り込みから8時間以上たったとき。DSの最新のCSVを取り込む
新しいバージョンがあります入力が終わると自動で再読み込みされる。今すぐなら再読み込みする

「最終取込」の表示

「予約一覧」タブの上に、最後にCSVを取り込んだ日時が大きな白いバッジで出ます。横に「1時間23分前」のような経過時間、取り込んだ人と件数が並びます。8時間以上たつと赤くなります。「このデータは最新か」を一目で確かめられます。

05CSVを取り込む

⚠ 必ず守ること

取り込むCSVは、DSからダウンロードしたファイルをそのまま使ってください。Excel等で開いて保存し直すと、登録日時の精度が落ち、複数台の予約が1件にまとまって消えてしまう事故につながります。内容の確認だけなら開いても構いません。

  1. 「予約一覧」タブを開く

    右上の「CSVを取り込む」を押します。

  2. ファイルを選ぶ、または貼り付ける

    「CSVファイルを選ぶ」でファイルを指定するか、内容をそのまま貼り付けます。

  3. 「内容を確認する」を押す

    まだ保存はされません。新規・更新・時刻の変更・キャンセルの件数と、何がどうなるかがここで表示されます。

  4. 赤枠の警告が出ていないか確認する

    ファイル違いや登録日時の欠落を検知すると赤枠で警告が出ます。心当たりがなければ、取り込みを中止してファイルを確認してください。

  5. 「取り込む」を押して確定

    ここで初めてデータベースに反映されます。

取り込むと予約の状態がこう変わる

DS側で起きたことアプリでの扱い
予約の中身（行先・場所・メモ等）が変わったその予約が変更ありになる（通常のものだけ。キャンセル・貸切・ジャンボなど、人が付けた状態はそのまま）
予約の時刻が変わった（同じ電話番号・同じお客様名の新しい予約が入った）元の予約はキャンセルになり「→ 07:50に変更」が付く。変更後の新しい予約が変更ありで入り「← 07:45から変更」が付く
1時間以上先の予約が、CSVから消えたキャンセルになる（直前の予約が消えるのは「配車が終わった」ためなので変えない）
内容が同じ「変更なし」。何もしない

✓ 消えないもの

担当者・チェック・申し送りは、CSVを何度取り込んでも消えません。「変更あり」の確認が済んだら、状態の欄で「通常」に戻してください（戻したあとは、内容がまた変わるまで変更ありには戻りません）。

06担当者・状態・チェック

日別の配車ボード・全体配車ボードとも、行の中の欄を選ぶだけでその場で自動保存されます。保存ボタンはありません。これらは誰でも操作できます。

欄できること
状態5つを手で切り替える：通常／変更あり／キャンセル／貸切／ジャンボ。貸切は、通常のタクシー呼び出しではなく貸切の予約のとき。ジャンボは、ジャンボタクシーの予約のとき
担当者乗務割の対象になっている人から選ぶ。決まっていないと「— 未割当 —」がオレンジで表示される
済確認が済んだ印としてチェックを入れる（毎日の確認は03）
編集（✎）予約の内容（迎車場所・メモ・電話番号など）を直接修正する。管理者のロックを解除したときだけ表示される（後述）

07行の色と表示の見方

行全体の色は「状態」だけで決まります。行の左端の太い縦線も同じ色で、離れて見ても状態が分かります。

表示意味
新着引き継ぎ以降にDSへ登録された予約（行は水色）。状態を変えると、その状態の色が優先され、縦線が二重になる
変更あり予約の時刻や内容が変わった予約（行は黄）。時刻変更の新しい予約には「← 07:45から変更」が付き、押すと元の予約の日が開く
貸切貸切の予約（行はピンク）
ジャンボジャンボタクシーの予約（行は緑）
キャンセル取り消された予約（行は灰色で打ち消し線）。時刻変更の元の予約には「→ 07:50に変更」が付き、押すと変更後の予約の日が開く
— 未割当 —担当者がまだ決まっていない予約。担当者の欄だけオレンジ。画面上部の「未割当 17件」も同じオレンジ。キャンセル行の未割当だけは灰色

担当者は人ごとに色が決まっていて、乗務割の名前と同じ色で表示されます（全員が別の色です）。

08乗務割

日別・全体ボードの上の「乗務割」（クリックで開く）に、その日の乗務員が区分ごとに並びます。/shift（月次シフト）の内容が自動で反映されます。

区分どう決まるか
普通・遅番シフトの①・③の人。急な変更は下の「＋追加」「×」で、その日だけ直せる
スクール・スクール原町・乗合・貸切シフトのコード（①S・①H・SH・SHS・S・貸切）の人
交流シフトに対応するコードがなく、「＋追加」で手で入れる

急なシフト変更への対応（その日だけ）

  • 名前の横の×を押すと、その人をその日の乗務割から外せます（確認メッセージが出ます）。/shiftのシフト自体は変わりません。
  • 「＋追加」で、その日だけ別の人を入れられます。外した人は「（除外中・戻す）」と出て、選び直すと元に戻ります。
  • 基本の担当を変えたいときは、「シフトを編集」から /shift で直します。

名前が赤の人は、まだ出勤の打刻がありません。薄い人は、すでに退勤しています。

09引き継ぎ・申し送り

日別の配車ボード上部の「前回の引き継ぎ」から記録します。ここで押した時刻が「新着」の基準になり、以降に入った予約だけが新着として表示されます。

  • 押し忘れても大丈夫：毎日19時に自動で基準が立ち上がり、翌朝10時まで（19時から15時間）、19時以降に入った予約が新着になります。
  • 手動で押した記録も、15時間たつと古くなり、新着の判定には使われなくなります（「期限切れのため、今は新着の判定をしていません」と出ます）。
  • 申し送り内容だけを書き換えたいとき（新着の基準は動かしたくないとき）は、「✎ 申し送りを書く」を使います。

10記録を確認・元に戻す

パネルできること
変更履歴予約の追加・変更・削除を新しい順に表示。項目ごとの変更前後の値も見える。「元に戻す」でその変更だけを取り消せる（「変更あり」の予約が何がどう変わったかは、ここで確認できる）
過去履歴（予約一覧内）削除された予約を、お客様名の読み順で確認できる（この画面からの復元はできない）

11管理者だけの操作

/haisha?admin で開くと、画面下部に「管理者ロック解除」が出ます。押して管理者アカウントでログインすると使えます（普段のスタッフ画面には出ません）。

  • 予約の編集（✎）・＋新規予約 — ロック中は、✎の列と「＋新規予約」が隠れ、予約一覧の行をクリックしても編集は開きません
  • 予約の削除
  • 「配車に関わる人の設定」 — 担当者の選択肢・乗務割から外す人（事務職など）をチェックで管理する

✓ ロック中でもできること

担当者・状態・「済」の操作、乗務割の追加・除外（×）、毎日の「全て確認済み」は、ロック中でも誰でもできます。予約の中身を書き換える操作だけが管理者限定です。

ご参考

?adminは画面の出し分けだけで、本当のアクセス制限ではありません。実際の権限はログインで決まります。

12印刷する

日別の配車ボード・全体配車ボードとも、右上の「印刷」から出力できます。操作用のボタンやナビゲーション、警告バナーは印刷時に自動的に隠れます。

13もしもの備え：毎朝の紙の予備

システム（Supabase）側の障害で、一時的にアプリが使えなくなることがあります（2026年8月に実際に発生）。その間も配車業務を止めないよう、毎朝、紙の予備を用意しておきます。

  1. 始業時に「日別の配車ボード」を開く

    「経過分も表示」を押して、その日の予約が全件見えている状態にします。

  2. 右上の「印刷」を押す

    その日の配車表を紙に出力しておきます。

  3. アプリが使えなくなったら、この紙を見ながら電話でやり取りする

    システムが直るまでの間、担当者・状態は口頭・電話で確認して配車を進めます。

  4. 復旧したら、紙の間に入った分をアプリに反映する

    紙の予備は「その日の朝時点の記録」なので、障害の間に決まった変更（新規予約・担当変更等）は復旧後にアプリへ入れ直してください。

✓ どんな時に見るか

画面が真っ白・エラーが出て動かない・「システム側で一時的な問題が発生している可能性があります」という案内が出た、といった場面で使います。ふだんは特に何もしなくて構いません。

14困ったときは

症状対応
