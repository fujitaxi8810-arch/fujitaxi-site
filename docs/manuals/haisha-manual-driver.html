配車管理 乗務員マニュアル

対象：乗務員 URL：/haisha 版：2026年10月15日版（最新仕様）

配車管理（/haisha）は、事務所が組んだ当日の配車を確認するための画面です。ふだんは見るだけで操作は不要です。ログインも要りません。ただし日勤（夕方）と遅番の方は、「予約チェック」とサインをお願いします（04）。

01開き方

  1. 日勤：夕方・引き継ぐ前

    紙の予約表と配車ボードをWチェックし、日別の配車ボードの右端の「済」に全部チェックを入れます（キャンセルは対象外）。全部入ったら、画面の一番上の「日勤（夕方）の確認済み」にチェックを入れて、確認した日勤の人の名前を選びます。全部の「済」が入るまでは押せません。

  2. 遅番：業務終了後に、二人でWチェック

    CSVを0時以降に出力し、最新であることを確認してから、二人でWチェックします。完了した分は、紙の予約表と配車ボードの両方にレ点を入れます（未完了は、配車ボードにはレ点せず、紙のみ）。全部の「済」が入ったら、画面の一番上の「全て確認済み」にチェックを入れ、「Wチェックが完了した」のまま、電話番ではない側の人の名前を選びます。日勤のサインが無いと押せません。

  3. やむを得ない場合：紙のみ → 翌朝の日勤が完了

    二人でWチェックできないとき（相方が急病・事故・緊急の呼び出し／終了時間が大きく違う／遅番が1名しかいない／システムの障害）は、紙の予約表のみにチェックします。翌朝、日勤が全て完了して「全て確認済み」にチェックを入れ、「日勤が朝にチェックした」で日勤の人の名前を選びます（朝7時以降は最初からこの場面が選ばれます）。

  4. サインする人

    段階サインする人画面で選ぶ項目
    日勤（夕方・引き継ぐ前）確認した日勤の人「日勤（夕方）の確認済み」
    遅番（業務終了後、二人でWチェック完了後）電話番ではない側の人「全て確認済み」→「Wチェックが完了した」
    やむを得ない場合（紙のみチェック）→翌朝の日勤日勤の人「全て確認済み」→「日勤が朝にチェックした」

    サインできるのは、小林隼人・渡部晃・堀内洋伯・荒智章・目黒圭吾・中橋常郎・菅原元輝・小林結の8名だけです（日勤の候補は、確認する日の前日に日勤で出ている人。小林結さんはシフトに無いため、平日（土・日・祝日を除く）だけ日勤の候補に出ます）。サインした人は、責任をもって対応してください。

  5. 緑の表示になれば完了

    「✓ 本日の予約は全て確認済み　日勤（夕方）：○○　確認：△△」と出ます。押し間違えたときは、チェックを外すと取り消せます。この緑の表示は、朝8時になると自動で消えます。

⚠ 日勤のサインは必須／朝7時までに

日勤（夕方）の確認済みが入っていないと、遅番の「全て確認済み」は押せず、完了になりません。朝7時を過ぎても終わっていないと、「🚨 朝7時を過ぎても…再チェックしてください」という強い警告に変わります。確認のあとに新しい予約が入った場合も、赤に戻るので、その予約を確認して、もう一度「全て確認済み」を押してください。

05困ったときは

症状対応
自分の名前の行が見当たらない「経過分も表示」を押すと、時刻を過ぎて消えた予約も見られます
画面が固まる・表示が古い一度画面を閉じて開き直してください（Ctrl+F5）
「全て確認済み」が押せないまだ「済」が入っていない予約があります（赤い警告の「未チェックを確認する」を押すと、隠れた分も表示されます）。または、日勤（夕方）の確認済みが入っていません（日勤のサインが必要です）
名前の候補に自分が出ない候補は場面で変わります（「どの場合ですか」を確認）。それでも出ないときは、事務所に確認してください
それでも解決しない事務所に電話で確認してください
